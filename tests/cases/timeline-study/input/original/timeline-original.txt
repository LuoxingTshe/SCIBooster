可以。检索更多综述后，我认为第二部分完全可以比现在的“相地—McHarg—Steinitz—GIS—WLC”丰富很多，而且 \(y=f(x;\theta)\) 的真正价值也会因此显现出来：**它不是用来证明所有方法属于同一谱系，而是把不同历史支线放到同一个结构坐标系中比较。**

现有综述支持至少三条并行发展的传统：

- **land suitability / ecological planning**：场地调查 → 叠图 → 适宜性分类 → GIS空间评价；
- **visual/perceptual landscape assessment**：专家评价 → 心理物理实验 → 认知/体验评价 → 图像与机器学习；
- **decision analysis / MCDA**：简单规则 → 权重聚合 → AHP/效用/超越关系 → fuzzy/OWA → sensitivity/SMAA → participatory/collaborative MCDA。

Collins et al. 对美国land-use suitability的历史综述明确从20世纪初开始追踪技术节点；Malczewski进一步把手工叠图、GIS以及多准则适宜性分析放入同一历史框架。与此同时，Zube等1982年对1965–1980年160余篇景观感知文献的综述已经识别出expert、psychophysical、cognitive和experiential四种并行范式，因此不能把“景观评价史”等同于“GIS适宜性分析史”。:chatgpt-content-reference{index="0"}

## 我建议的“形式化简史”骨架

这里的“复杂度”不是“新方法一定优于旧方法”，而是指**模型中被显式表示和操作的结构越来越多**。

| 大致时期 | 方法/模型节点 | 形式化上新增了什么 | 用 \(y=f(x;\theta)\) 看 |
|---|---|---|---|
| 前现代—20世纪初 | **经验性场地判断 / survey** | 场地信息被观察、分类，但判断规则主要存在于实践者经验中 | \(x\) 可辨认，\(f\) 大量隐式 |
| 20世纪初—1960s | **手工地图叠置、资源调查、land capability** | 不同空间属性被拆成独立图层，判断开始空间显式化 | \(x=(x_1,x_2,\ldots)\)，\(f\) 开始外显 |
| 1960s–70s | **McHarg式 ecological suitability / overlay** | 分类、分级、机会—限制、叠图综合成为可重复程序 | \(f\) 成为显式规则 |
| 1970s | **FAO Land Evaluation / suitability classification** | land qualities、land-use requirements、适宜性等级被规范化 | \(x\)、评价标准和 \(y\) 类别被明确 |
| 1970s | **Hopkins suitability-method taxonomy** | 不同适宜性地图生成方法第一次被系统比较 | 开始讨论不同 \(f\) 的差异 |
| 1965–80s | **visual landscape assessment：expert / psychophysical / cognitive / experiential** | 人的感知、评分和偏好成为可测量评价输出 | \(x=\)景观/图像特征，\(y=\)感知评价 |
| 1980s–90s | **计算机化overlay / Boolean GIS evaluation** | AND/OR、约束条件、阈值成为明确逻辑运算 | \(f\) 成为布尔规则，\(\theta\)含阈值 |
| 1990s | **WLC / additive value models + GIS** | 多因子标准化、赋权、加总形成连续评价值 | \(y=\sum w_ic_i(x)\) |
| 1990s–2000s | **AHP + GIS-MCDA / MAUT-MAVT / ELECTRE-PROMETHEE** | “偏好如何进入模型”本身被方法化 | AHP主要产生 \(\theta\)；不同MCDA改变 \(f\) |
| 1990s–2000s | **Fuzzy evaluation** | 从硬阈值转向连续membership，处理“适宜/不适宜”之间的模糊边界 | 首先改变 \(x\to c_i(x)\) 的映射 |
| 2000s | **OWA** | 除criterion weight外，引入order weights，可表达不同补偿程度和决策策略 | \(f\) 获得额外参数，决策规则本身可调 |
| 1998–至今 | **SMAA / stochastic MCDA** | 权重或输入不再是单一点，而成为分布/可探索空间 | \(\theta^\*\rightarrow\Theta\) |
| 2000s–2010s | **Sensitivity / uncertainty / robustness analysis** | 研究对象从“结果是什么”扩展到“结果如何随参数变化” | \(y(\theta^\*)\rightarrow\{y(\theta)\}\) |
| 2000s–2020s | **participatory / collaborative spatial MCDA** | 多个利益相关者、多个价值结构被显式纳入 | \(\theta\rightarrow\{\theta_1,\theta_2,\dots\}\) |
| 2010s–2020s | **landscape-level integrated MC assessment / ecosystem services** | 生态、社会、经济、感知及利益相关者维度被共同空间化 | \(x\) 的维度和来源显著扩大 |
| 2020s | **ML / deep-learning landscape evaluation** | 评价函数乃至特征本身开始由数据学习，而非完全人工规定 | \(f\rightarrow f_{\theta}\)，且部分 \(x\) 表征也被学习 |

这条时间线的好处是，它不是简单地说“计算机越来越高级”，而是可以指出**每次方法迭代到底形式化了模型的哪一部分。**

### 1. 经验判断 → 空间信息被拆解

Collins、Steiner和Rushman 2001的历史回顾非常适合做这一段的骨架。他们把美国land-use suitability analysis的有记录历史追溯到20世纪初，并一路讨论到世纪末的计算方法。Malczewski 2004同样把早期手工overlay明确放在现代GIS suitability analysis的技术谱系前端。:chatgpt-content-reference{index="1"}

这一阶段不应该写成“没有模型”，而应该写成：

\[
\text{整体经验判断}
\rightarrow
\text{多个可分别描述的场地属性}
\]

也就是 \(x\) 开始被拆解。

### 2. McHarg：不是“数学化”，而是 \(f\) 的程序化

McHarg节点仍然值得保留，但他的历史意义最好重新定义。

1977年对Penn生态规划方法的概述描述得非常清楚：先识别和分析构成环境的因素和过程，再根据使用者的价值体系进行解释，形成opportunities和constraints，最后通过map overlay综合为suitability classes。:chatgpt-content-reference{index="2"}

所以McHarg最重要的变化并不是：

\[
\text{经验}\rightarrow\text{数学}
\]

而是：

\[
\boxed{\text{implicit }f\rightarrow\text{procedural }f}
\]

评价规则开始变成别人能够重复实施的一套操作程序。

这非常适合你的形式化史。

### 3. 1970年代其实应该增加两个你原稿没有的大节点

第一个是 **FAO 1976 Framework for Land Evaluation**。

它不是景观设计理论，但对“评价如何被形式化”非常重要。FAO明确规定land characteristics、land qualities、land-use requirements、limitations以及suitability classification等概念，并给出从土地描述、用途要求比较到适宜性分类的程序。:chatgpt-content-reference{index="3"}

而且FAO后来对这段历史的回顾明确说明，到1970年前不同国家已经发展出大量自己的land evaluation systems，因为难以相互比较，才产生了标准化框架的需求。:chatgpt-content-reference{index="4"}

这个案例甚至比Steinitz更符合你此前说的：

> “大量先行存在的方法被显式组织和一定程度标准化。”

但要注意，它是**land evaluation史**，不能直接冒充landscape planning史。

第二个是 **Hopkins 1977**。

这篇很适合你的论文，因为Hopkins当时就指出，大量land suitability case studies缺乏共同框架，因此建立了已有方法的taxonomy并进行比较。:chatgpt-content-reference{index="5"}

它几乎可以成为你采用 \(y=f(x;\theta)\) 的一个历史先例：**异质方法太多，所以需要更高层的共同描述框架。**

### 4. 必须补一条“视觉景观评价”的旁支

否则你的标题叫“景观评价方法”，正文却实际上只讲 **land suitability evaluation**。

Zube、Sell和Taylor 1982回顾1965–1980年的160余篇文献时，已经把landscape perception/evaluation研究分成四大范式：

\[
\text{expert}
,\quad
\text{psychophysical}
,\quad
\text{cognitive}
,\quad
\text{experiential}
\] :chatgpt-content-reference{index="6"}


Daniel 2001后来回顾这一传统时，又把20世纪后半叶视觉景观质量评价概括成expert approach与perception-based approach之间长期存在的张力，并指出两者都承认景观物质特征与人的感知/判断之间存在互动。:chatgpt-content-reference{index="7"}

这里其实能证明你的形式语言很有用。

空间适宜性评价可能是：

\[
x=\text{slope, soil, hydrology, accessibility}
\]

而视觉评价可能是：

\[
x=\text{visible landscape characteristics}
\]

\[
y=\text{scenic preference / visual quality score}
\]

虽然二者的**对象、数据和评价目的完全不同**，但都可以讨论：

\[
x,\quad f,\quad \theta,\quad y
\]

哪个部分是经验的、显式的或者被学习得到的。

这能防止你无意中把“land suitability史”写成“landscape evaluation全部历史”。

### 5. GIS初期：Boolean overlay 应该独立成一个节点

你现在很容易从McHarg直接跳到WLC，但中间其实有非常重要的一层：

\[
\text{Boolean overlay}
\]

例如：

\[
A(x)\land B(x)\land \neg C(x)
\]

这也是一个真正意义上的形式化评价模型。

Malczewski在GIS suitability文献中把**Boolean overlay**和**WLC**称为GIS多准则评价中的两种基本组合规则：前者是non-compensatory，后者是compensatory。:chatgpt-content-reference{index="8"}

这一步对你的文章尤其漂亮，因为它说明数学化并不等于“权重”。

可以存在：

\[
y=f(x;\theta)
\]

但

\[
\theta=\{\text{thresholds}\}
\]

而没有：

\[
\mathbf w
\]

这能帮助你后面非常自然地说明：**权重只是参数化判断的一种形式，而不是全部。**

### 6. WLC才是一个真正重要的“参数显式化”节点

然后才进入你的核心：

\[
S(x)=\sum_iw_ic_i(x)
\]

Malczewski 2000称WLC为GIS中最常使用的决策规则之一，同时特别指出它经常因为分析者没有理解其假设而被误用。:chatgpt-content-reference{index="9"}

这里从你的语言看，真正发生的是：

\[
f(x)
\rightarrow
f(x;\mathbf w)
\]

至少一部分“不同评价维度应该如何trade off”的问题被压缩成一个有限维参数：

\[
\mathbf w=(w_1,\ldots,w_n)
\]

这就是你的第一篇方法论文真正开始关心的地方。

### 7. AHP不要和WLC写成同一类东西

这一点我建议第二部分明确写出来。

很多景观/GIS文章喜欢写：

> AHP-WLC method

但从你的结构语言看，它们承担完全不同的功能：

**AHP主要解决：**

\[
\text{judgment}
\rightarrow
\mathbf w
\]

即如何得到参数 \(\theta\)。

而 **WLC解决：**

\[
(x,\mathbf w)
\rightarrow y
\]

即如何聚合。

所以：

\[
\boxed{
\text{AHP}\approx\theta\text{ elicitation}
}
\]

\[
\boxed{
\text{WLC}\approx f
}
\]

这非常有解释力。

2006年的GIS-MCDA综述已经检索并分类了1990–2004年超过300篇同行评审GIS-MCDA论文，说明这一时期GIS与MCDA的结合已经成为明显的方法领域。:chatgpt-content-reference{index="10"}

更广泛的环境MCDA综述则把AHP、MAUT/MAVT、ELECTRE/PROMETHEE等作为不同方法家族；2017年对约3000篇环境MCDA论文的文本挖掘也显示AHP/ANP、TOPSIS、outranking和MAUT/MAVT已经形成主要方法群。:chatgpt-content-reference{index="11"}

### 8. 这里可以第一次真正把“模型复杂化”拆开

1990s以后，并不是简单出现越来越复杂的公式，而是**不同研究开始解决不同层次的问题**。

例如：

**Fuzzy methods**主要处理：

\[
x\rightarrow c_i(x)
\]

的问题。

坡度15°究竟应该突然从“适宜”跳到“不适宜”，还是：

\[
\mu_{\mathrm{suitable}}(x)\in[0,1]
\]

连续变化？

所以fuzzy首先形式化的是**标准化和类别边界的不确定/模糊性**。

而 **OWA** 进一步改变聚合规则本身。它同时存在criterion weights和order weights，因此可以产生从保守到补偿程度不同的一系列决策策略。Malczewski 2006明确将其描述为可以通过参数改变产生不同decision strategies/scenarios。:chatgpt-content-reference{index="12"}

因此你可以写：

\[
\text{Boolean}
\rightarrow
\text{WLC}
\rightarrow
\text{OWA}
\]

不是简单：

> 简单算法 → 高级算法

而是：

\[
\text{hard constraint}
\rightarrow
\text{fixed compensatory trade-off}
\rightarrow
\text{parameterized decision strategy}
\]

这个历史解释会高级很多。

### 9. SMAA是另一种性质的变化：不再寻找一个 \(\theta\)

SMAA 1998的原始论文非常适合你的历史结构。

它明确以**exploring the weight space**为核心，并允许不精确或不确定输入用概率分布表达；甚至在决策者无法准确给出偏好的情况下，反过来研究“什么样的valuation会支持某个alternative”。:chatgpt-content-reference{index="13"}

所以它不是简单：

\[
f_{\mathrm{simple}}\rightarrow f_{\mathrm{complex}}
\]

而是认识对象发生改变：

\[
\theta^\*
\]

变成：

\[
\Theta
\]

即：

\[
y=f(x;\theta^\*)
\]

变成研究：

\[
\{f(x;\theta):\theta\in\Theta\}
\]

2020年的SMAA系统综述统计了1998–2017年118篇相关论文，也确认SMAA已经发展成处理评价与偏好参数中不完整、不精确和不确定信息的一整个方法家族。:chatgpt-content-reference{index="14"}

这应该成为你时间线上的独立节点。

### 10. Sensitivity / uncertainty analysis也应该独立出来

2004年的综述检查了28项GIS-MCE敏感性分析研究，发现敏感性分析当时仍不常见，而最常见的方法正是**改变criteria weights观察结果是否显著变化**。:chatgpt-content-reference{index="15"}

到了2014年，已经出现明确的spatially explicit uncertainty and sensitivity analysis：通过Monte Carlo扫过权重空间，生成大量suitability maps，然后计算平均值、不确定性及不同权重的空间敏感度。:chatgpt-content-reference{index="16"}

这意味着历史上又发生了一次非常重要的转变：

原来研究：

\[
y
\]

后来研究：

\[
\frac{\partial y}{\partial \theta}
\]

或者更广义地：

\[
\theta\mapsto y(\theta)
\]

**模型不再只用于评价景观，也开始用于评价自己的评价。**

我觉得这句话甚至可以留到正文里。

### 11. 参与式MCDA是 \(\theta\) 从“一套价值”变成“多套价值”

MCDA还有另一条很重要的演进，不应该全部讲成数学技术升级。

2000s之后GIS-MCDA越来越多地进入participatory / collaborative spatial decision making。2020年的系统综述专门回顾了collaborative spatial multicriteria evaluation，涵盖urban planning、land-use assessment、environmental assessment以及交互工具的发展。:chatgpt-content-reference{index="17"}

2021年的空间规划综述进一步指出，规划方法已经从单纯positivist取向向deliberative approaches扩展，并讨论不同MCDA方法如何作为真实的参与式学习工具。:chatgpt-content-reference{index="18"}

你的符号语言可以非常简洁地说明这个变化：

以前：

\[
\theta=\theta^*
\]

后来：

\[
\Theta_{\text{stakeholders}}
=
\{\theta_1,\theta_2,\ldots,\theta_k\}
\]

这和SMAA的\(\Theta\)虽然数学表现类似，但**认识论来源不同**：

- SMAA：不确定偏好空间；
- participatory MCDA：真实存在的多元价值空间。

这个区别值得保留。

### 12. 2010s的“landscape-level MC assessment”把问题重新扩大

Allain等2017专门系统综述了具有**spatial + participatory**特征的landscape-level multicriteria assessments，并指出景观尺度的问题涉及multiple views、multiple organizational levels、复杂时空格局以及uncertainty。:chatgpt-content-reference{index="19"}

因此可以把这一阶段理解为：

早期形式化的方向是：

\[
\text{把复杂景观压缩成简单可计算模型}
\]

而成熟以后又出现反方向：

\[
\text{把社会、价值、不确定性和空间复杂性重新纳入模型}
\]

这比“模型越来越复杂”更有历史解释力。

### 13. 2020s最后可以加一个非常漂亮的新节点：\(f\) 本身开始被学习

这个节点我原本认为可以不写，但检索以后，我觉得**非常适合你的文章结尾**。

传统WLC中：

\[
f
\]

是研究者写下来的。

例如：

\[
f(x;\mathbf w)=\sum_iw_ic_i(x)
\]

但机器学习进入景观评价以后：

\[
f_\theta
\]

可以通过数据训练获得。

2021年已有研究将社交媒体图像、公众scenicness ratings与deep learning结合，在大尺度上建立景观美学质量模型；2023年的visual landscape modeling综述也已经把ML/ANN作为预测景观评价结果的方法讨论。:chatgpt-content-reference{index="20"}

视觉景观评价尤其明显：

传统模型：

\[
\text{researcher-defined features}
\rightarrow
\text{rating}
\]

开始变成：

\[
\text{image}
\xrightarrow{f_\theta}
\text{predicted aesthetic evaluation}
\]

甚至部分特征表征本身也由模型学习。

因此你这条“形式化史”到今天出现了一个很有意思的回环：

\[
\text{implicit human }f
\]

↓

\[
\text{explicit rule-based }f
\]

↓

\[
\text{explicit mathematical }f(x;\theta)
\]

↓

\[
\boxed{\text{learned }f_\theta}
\]

这里就会出现一个非常现代的问题：

> **当评价函数再次变得难以直接解释时，我们是否从“显式形式化”走向了新的计算黑箱？**

这个问题和你的“可审计性”主张天然衔接。

## 因此，我建议第二部分不要写成十几个年代小节

真正成文时可以压成 **5个阶段**，但每阶段内部有上述细节点：

\[
\boxed{
\begin{array}{l}
1.\ \text{经验判断与空间调查}\\
\downarrow\\
2.\ \text{规则化、分类与叠图}\\
\downarrow\\
3.\ \text{参数化与多准则聚合}\\
\downarrow\\
4.\ \text{不确定性、多价值与模型空间}\\
\downarrow\\
5.\ \text{数据驱动与学习型评价}
\end{array}}
\]

然后让 \(y=f(x;\theta)\) 贯穿，但每一阶段只问一句：

> **这一阶段究竟把哪一部分变得更加显式？**

你最后得到的其实不是普通的技术年表，而是一条很有辨识度的历史叙事：

\[
\boxed{
\text{对象被拆解}
\rightarrow
\text{规则被显式}
\rightarrow
\text{参数被显式}
\rightarrow
\text{参数的不确定性被显式}
\rightarrow
\text{多元价值被显式}
\rightarrow
\text{函数本身开始被学习}
}
\]

我认为这比原来“相地 → McHarg → Steinitz → GIS → WLC”强很多。尤其关键的是，**AHP、fuzzy、OWA、SMAA、sensitivity analysis不再是一串算法名，而分别对应 \(x\)、\(f\)、\(\theta\)、\(\Theta\)、\(y(\theta)\) 不同层面的变化。**这正是你发明这套结构化语言最有说服力的用途。
