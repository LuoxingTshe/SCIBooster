# 形式结构与编码边界
本页为本项目操作性约定，来源是聊天讨论后的整理，不是既有公理体系。

核心：y = f(x; θ_eval)
展开：x = Rρ(z)，s = Cα(x)，y = Aβ,w(s)。
θ_eval = (α, w, β)；若把表示层纳入，则 y = F(z; θ_all)，θ_all = (ρ, α, w, β)。
这修正了旧聊天把已经给定的 x 与上游 ρ 同时无条件塞进同一 f 的记号混用。
E(j) 可产生参数或参数约束；学习机制 ℒ(D_train) 可估计多个层的参数。
模型签名 M = (R,C,E,A,U,P,L) 是多轴编码，不是七个互斥家族。

|字段|功能|边界|
|---|---|---|
|R|世界到可计算表示|GIS 是环境/数据设施，不自动成为独立评价算法|
|C|描述变量到评价尺度|标准化不总是价值函数；模糊隶属度不等于概率|
|E|偏好获取、判断到参数/约束|AHP 在 AHP-WLC 中常承担赋权，但完整 AHP 可跨 E/A|
|A|准则综合/比较|输出可为分值、等级、序、关系；不能强迫超越关系产生单一标量|
|U|不确定性、敏感性、稳健性分析|三者分别编码，参数集合与概率测度分别记录|
|P|价值多元、参与和协商机制|多套权重不足以证明具有实质参与|
|L|数据估计和学习机制|回归早于深度学习；不能把 2017 视作所有学习型评价起点|

WLC：y = Σᵢ wᵢ cᵢ(xᵢ;αᵢ)，常用 wᵢ≥0、Σwᵢ=1。加法模型的适用性依赖偏好、尺度与补偿假设；归一化不证明这些假设成立。
Boolean：sᵢ = 1[xᵢ 满足阈值条件]，再经 AND/OR 等逻辑组合。
纯 OWA：A_v(s) = Σᵢ vᵢ s_(i)，s_(i) 按大小排序，vᵢ 是位置权重。一般不等于对固定准则使用不等权重的 WLC；双权重 GIS 扩展须另行写明。
学习：θ̂ = ℒ(D_train; architecture, loss, protocol)，ŷ = f(x;θ̂)。C/A 可能融合且不可单独识别，不强行拆分。
不确定性：θ ∈ Θ_U；需要概率时另写 θ~pθ，Y=f(X;θ)。集合本身不产生排名概率，均匀采样也是假设。
价值多元：{θ^(k)}，并记录群体、获取过程、分歧和聚合机制。可进一步有每个群体自己的 p(θ|k)。

超越关系、TOPSIS、完整 AHP 和端到端学习为边界压力测试：A 可推广为候选集上的比较映射；模型输出域必须明示。此推广尚待实证编码验证。

未来闭环（愿景）：z_t → R → x_t → f → y_t → D_decision → a_t；z_(t+1)=T(z_t,a_t,ε_t)。
环境响应依赖当前状态和外部扰动，并非仅由行动决定。决策另含预算、制度与价值约束。该闭环图式不证明系统稳定性、可控性或 AGI 能力。

## 后期制图约定
时间线按 tradition 分泳道；method_origin 和 representative_application 分符号。
仅对证实的历史影响绘制实线因果箭头；本轮没有足够证据确认这种边。
functional_comparison 用虚线、same_period 用对齐，不把发布时间先后画成传承。
作者分期用半透明时间带；未知年份不填伪造的数值。

## 时间线叙述补充（2026-10-07）
跨模型比较时写 y=f_m(x;θ_eval)，m记录结构/方法选择，不强迫不同输出域的模型共享一个数值参数空间。候选集依赖者写 f_m(X;θ)。古代经验与图层实践的函数表达仅为回溯性分析，不是其原始算法。主题线索相互重叠，不同于模型家族或因果传承。
