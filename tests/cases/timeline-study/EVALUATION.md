# Forward-test evaluation

Read after the agent produces an independent first output. These are qualitative invariants, not a prewritten canonical answer. Evidence outside the input may justify a different conclusion only if explicitly inspected and recorded.

|Input|Useful evaluation question|
|---|---|
|H05 Repton|Does the output preserve scenario/image comparison rather than silently infer multicriteria map weighting?|
|H11 Eliot|Does it retain the report/reproduction date caveat and avoid inventing a WLC formula or a world-first claim?|
|DS014 WLC|Are criterion conversion, weights and aggregation assumptions distinguished? Is an undocumented planning h kept unknown?|
|DS020 OWA|Are sorted-position weights distinguished from criterion weights? Is the formula presented as analyst normalization rather than a verbatim source equation?|
|DS024 ELECTRE|Does it retain relational/choice outputs and candidate-set scope rather than impose independent scalar scoring?|
|DS017 robust ordinal regression|Does it separate compatible-function sets from probabilities and necessary/possible relations from rank probability?|
|H12 ASLA|Is a professional institution kept as context rather than reconstructed into an invented landscape algorithm?|
|DS010 taxonomy|Is the method-level review object distinguished from a concrete landscape evaluation application?|
|DS039 ScenicNet|Are representation learning and evaluation distinguished where possible, without assuming all learned models are opaque?|

Check all outputs for:
- fields supported by a traceable source vs project reconstruction;
- no title/DOI identity evidence upgraded into a detailed implementation claim;
- no fabricated variables, scales, decision thresholds or observed feedback;
- current model omissions not proclaimed permanently irreducible;
- cross-model equivalence and family-count claims no stronger than the inspected evidence;
- actual uncertainty analysis separated from potential uncertainty and stakeholder plurality.

Assess output usefulness and coding disagreements qualitatively. A reproducibility check against the old baseline is a separate test; it cannot establish independent coding agreement or semantic validity.
